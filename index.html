AI Architecture & Innovation Methodology

A plain-language breakdown of how a hand becomes a word.

Try it in the mirror
1

RGB Frame Capture

Webcam stream @ 60 FPS, normalized to 1280x720 RGB format.

2

Hand Landmark Detection

MediaPipe extracts 21 3D landmarks (x, y, z) per hand.

3

Coordinate Normalization

Scale and translation invariance using wrist base as origin (0,0,0).

4

Deep Neural Classifier

CNN-LSTM network captures spatial joint angles and temporal movement.

5

Translation & Voice Synthesis

Character sequence decoder + Web Speech API audio output.

Hardware & Software Specifications

Deployment Requirements

  • Frontend: Modern HTML5, CSS3 Glassmorphism Design System, JavaScript ES6+ (No Node dependencies required).
  • Vision Engine: Google MediaPipe Hands 21 3D skeletal landmark extraction architecture.
  • Deep Learning Model: TensorFlow / Keras Spatial 1D-CNN + Bidirectional LSTM.
  • Speech Engine: W3C Web Speech Synthesis & Web Audio API.
  • Data Visualization: Chart.js 4.4 CDN.
  • Minimum Client Specs: Any standard laptop/phone with an HD webcam (720p 30fps) and modern browser (Chrome, Edge, Safari, Firefox).
